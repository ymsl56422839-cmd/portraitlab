# 0.5.0 预设与取样点修管线

0.5.0 将修肤、明暗和色彩按组应用，并增加可指定供体的点修。新导入照片从中性参数开始，不自动套用柔肤；“重置修片”恢复当前范围的中性参数和 100% 总强度，下一次调整可以直接生效。重置修片保留独立的点修与交互布光；要撤销点修，使用点修工具的“撤销上一处”或编辑撤销。

这些变化使用已有依赖和经典算法。亮度统计驱动的自适应预设不是新神经模型；本管线不包含 ModelScope 神经修复模型，也不会为点修下载新权重。

## 预设怎样应用

目录共有 53 个入口：通用 27、长者人像 8、成人人像 10、少年人像 8。保留 0.4.1 的全部 52 个 ID 与收藏，新增 `auto_balance`。四类由用户选择，不运行年龄识别；部分黑白入口共享处理行为，53 个入口不代表 53 个独立算法。

| 处理组 | 主要参数 | 应用边界 |
|---|---|---|
| 修肤 | 柔肤、瑕疵淡化、匀肤、纹理、去痘、痘点识别、皮肤范围 | 保留现有明暗和色彩 |
| 明暗 | 曝光、面部补光 | 只调整预设列出的明暗项目，保留修肤和色彩；仅补脸的方案保留全图曝光 |
| 色彩 | 冷暖、饱和度 | 保留现有曝光、面部补光和修肤 |

内置方案应用后返回处理组、具体参数、统计与提示。已有非零总强度保留；若总强度原为零，应用预设或手动调整效果参数会将其恢复为 100%，避免出现调整了参数却一直不可见的状态。“原图／重置修片”是清除当前范围三组参数的明确操作。

自定义预设保留旧版的**完整参数快照**语义：应用时替换当前范围的修肤、明暗与色彩，并使用快照中的总强度；界面会说明这一点。保存预设不包含矩形位置、保护笔刷、点修数组或独立灯光配置。

## 自适应明暗的依据

标注“自适应”的明暗方案测量线性 RGB 的亮度中位数、亮部百分位、通道亮度上限和接近纯黑／过曝的比例；存在有效面部选区时另测面部亮度。计算据此选择受限的曝光或面部补光量，高光余量不足时限制增亮，并说明无脸、近黑、已过曝等情况。其他修肤、色彩方案仍是明确的参数操作。

全局预设从原片统计；局部预设从已经应用**全局修片**的底图统计框内像素，不把旧局部效果、点修或交互布光再次算入测量。局部预设保留矩形位置与大小。预设提交检查照片版本；分析期间发生其他编辑会返回冲突，要求基于最新照片重新应用。

这不等于自动白平衡、测得真实照明或理解拍摄意图，也不能恢复已经裁掉的亮部。统计目标可能不符合高调、低调或舞台照片的意图，应用后仍需查看实际曝光数值和画面。

## 自动痘点修复与取样点修

“痘点识别”控制检测灵敏度；“去痘强度”控制已检测痘点的修复量。旧记录没有识别参数时使用 `0.5`。检测继续使用 RapidRetouch 的紧凑红／暗斑点与分频修补方法，未检测到可修复点时显示提示。提高强度不会增加候选点；连片红痕、痘坑、弱对比斑点可能漏检，雀斑和妆面可能误判。保护笔刷与局部矩形仍约束经典自动修肤。

对于希望明确指定的一处瑕疵：

1. 放大检查，展开“取样点修”，点击“开始点修”。
2. 先点击纹理相近的干净皮肤作为供体，再点击需要修复的目标。
3. 按住 **Alt** 点击或使用“选取样本”更换供体；半径与强度影响之后添加的笔。
4. 用“撤销上一处”移除最后一笔，也可使用编辑撤销；Esc 结束点修并保留已有操作。

界面半径为图片短边的百分比，默认 1.5%（直径为短边的 3%），可调 0.2%～5%；每张照片最多保留 100 笔。点修作用在全局与矩形调整之后，使用自己明确指定的圆形目标，不受已有矩形或经典保护笔刷额外裁切。

每笔保存目标 `x/y`、供体 `source_x/source_y`、相对短边的 `radius` 和 `strength`。算法从本次点修层输入底图读取所有供体，按数组顺序叠加目标：后面的笔不会把前面刚修好的区域当作新的供体纹理。它从目标周边估计宽尺度色调，结合供体的真实细纹理，在线性光中混合并向圆盘内部羽化。供体或目标越界时只处理两者都有效的像素，并给出边缘提示；无有效像素时保留底图并说明原因。

算法来自 Chris Cork 的 [RapidRetouch Patch](https://github.com/crispin81/RapidRetouch/blob/d6f9a848fa5ba5628239b568777c5be3e7851a8e/engine/src/rapidretouch_engine/tools/patch.py)，固定提交 `d6f9a848fa5ba5628239b568777c5be3e7851a8e`，采用 **AGPL-3.0-only**。修改与来源哈希见[点修出处说明](../licenses/SPOT_REPAIR_NOTICE.txt)，完整条款见[LICENSE](../LICENSE)。它不自动选供体，也不是生成模型。供体选择不当仍可能复制不合适的纹理或改变局部特征。

## 顺序、缓存与设备

处理顺序固定为：

`原片 → 全局修肤／明暗／色彩 → 矩形局部增量 → 取样点修 → 交互布光 → 显示或导出`

全局和局部参数分别保存，局部仍是全局结果上的附加处理，不是区域内取消全局效果。点修数组独立保存并进入 JSON 导出记录。点修圆盘外精确保留的是点修层输入底图；后续布光、有损 JPEG 或缩放仍可能改变最终像素。

修片按原尺寸生成统一底图，预览和导出复用同一计算结果。全局、局部与点修有可重用的底图缓存；点修位置、半径、供体或强度变化会改变缓存键，仅改灯光不会重复修肤。无缩放的 PNG 可以逐像素比较；缩小预览与原尺寸导出存在重采样差异，不能直接逐像素比较两个不同尺寸的文件。

既有 NVIDIA GPU 合成保留，负责曝光、面部局部曝光、冷暖、饱和度、整体混合和 sRGB 编码。人脸／分割、修肤、痘点检测和取样点修仍在 CPU；点修使用最长边 512 像素的色调场与 256 像素的原尺寸纹理分块。布光深度分析有独立的 CPU／CUDA 选择，不能据合成设备标签判断每个阶段都在 GPU 上运行。

## 兼容性与验证边界

旧照片的 `params`、局部矩形、笔刷和自定义快照保留；新增的点修字段默认为空数组，痘点识别默认 `0.5`。升级不自动给旧照片重新套用内置预设。再次点击某个旧 ID 时使用新版按组行为，因此不能承诺与旧版整套覆盖得到同样的画面。缓存可按新版处理签名重算。

现有基础处理与 Depth Anything V2 Small 模型无需为本次功能重新下载；不完整或损坏的文件仍需按模型清单校验。独立 AI 运行组件仍用于原有布光分析与 GPU 合成，不能只靠一个模型文件替代完整运行时。

输入工作图和输出仍为 **8-bit sRGB**；阶段之间仍有 8 位量化。内部线性浮点运算不代表已经建立高精度、HDR 或 RAW 处理管线。

本次已通过的专项验证是点修模块 88 项测试，以及预设／点修 API 17 项测试，覆盖参数校验、合成瑕疵、恒等、范围外守恒、边缘、版本冲突、缓存、持久化和 PNG 预览／导出一致。完整发布回归结果由[验证记录](VALIDATION.md)另行汇总；这些测试没有替代跨肤色、年龄、妆容、胡须、暗光和多人照片的人工质量评估，也不证明普遍画质提升。
