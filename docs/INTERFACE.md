# 照影的界面与使用流程

照影（PortraitLab）的界面围绕两类任务组织：修片调整已有像素，光影重塑在原片上交互布光。中文名称用于软件显示，英文仓库名和 `PortraitLab.exe` 保持兼容。

0.4.0 的交互布光替换主界面的生成式流程，旧后端与历史生成记录保留兼容。单／双视图、缩放与照片库移除均在同一操作界面内完成。

## 常用操作

1. 选择修片或光影重塑，当前模块保持高亮。
2. 在当前模块导入照片，也可拖入文件或文件夹。导入后在当前模块选中新照片，连续添加保留之前的照片。
3. 修片单击预设只修改当前照片，可调整整体强度，展开手动参数。自定义预设只保存数值，不包含照片或笔刷。
4. 布光首次分析深度和人物选区，随后拖灯直接预览。方向光、点光源、聚光灯、柔光箱支持最多四灯及十个预设。作用范围分为“仅主体 · 保留背景”“仅背景 · 保留主体”“整张照片”，默认仅主体；可开启“显示作用选区”检查实际覆盖范围，高亮仅用于查看，不写入照片。“保留调整”保存当前照片的灯光参数及作用范围，支持撤销。未保留时离开会显示保留、放弃、继续布光。
5. 中央图像预览提供单视图、双视图。两个视窗各自选择原图、滑动对比或处理结果；分界线可分别拖动，放大平移后仍位于可见图像区域。两个视窗显示同一照片、同一套布光草稿；原图视窗不显示可编辑灯光控制点。
6. 批量同步明确显示张数，保留各张笔刷，并可撤销上一次批量操作。后续编辑冲突时拒绝覆盖。
7. 导出前明确数量和格式；导入未完成时禁止开始导出。关闭桌面窗口前等待尚未保存的参数写入。
8. 鼠标滚轮以指针位置缩放；滑块支持 1%～400% 显示比例，适应窗口恢复全图。双视图共享缩放比例和查看位置；放大后拖动画面平移。查看比例相对于原图尺寸，不表示已有原尺寸实时渲染。两窗获得焦点后也可用方向键平移、空格临时看原图；分界线支持左右键、Shift 加速及 Home/End。
9. 照片卡片提供单张移除，照片库提供移除选中；移除后可撤销最近一批。此操作只隐藏照片库记录，保留照片副本、编辑记录、外部原文件及已导出文件。处理中照片完成任务后再移除。

## 可用性验收原则

- 功能按钮使用明确中文，装饰性命名不替代操作说明。
- 主要说明和操作文字至少 12 CSS 像素；主要按钮至少 32 CSS 像素高，键盘焦点可见。小窗口以滚动和折叠容纳内容。
- 检查 1366×768 及相近高缩放可用区域，不能横向裁掉导入、模块切换或提交入口。原生窗口大小限制在当前屏幕工作区内。
- 反馈说明对哪张照片执行什么操作，以及是否涉及批量；成功状态不会假装预览已经完成。
- 未下载、已下载、校验中、已就绪、失败各有对应文案与动作。不可用操作同时解释原因。
- 经典 CPU/GPU 偏好、硬件可用性和实际执行设备分别处理。GPU 回退后显示实际 CPU，布光分析设备另行配置，实时预览分别显示图形加速或 CPU 预览。
- 布光范围切换后，范围说明与选区高亮同步改变。仅背景模式保护主体，羽化边缘依分割权重过渡；原图视窗不叠加作用选区。选区高亮不改变保存参数或输出图片。
- 调灯时关闭选区叠加，直接显示实际效果；所有可见视窗都在看原图时，将一个视窗切换到处理结果。中央状态说明范围、强度及是否保留，实际绘制完成后才提示更新；光源关闭、无有效灯光或强度为零时明确解释未生效原因。
- 更新后界面与后台能力不匹配时，提示关闭全部照影窗口重启，不误报照片未选择。重新打开一个窗口不能作为后台已更新的判断依据。
- 输入为空、处理中、失败、重复导入、连续切换照片、误触恢复和退出都是正常使用场景，需要检查。

这些是设计与验证准则，不等于已经完成专业无障碍认证或多人可用性实验。修片预览长边最多 1600 像素，交互布光长边最多 1024 像素，CPU 降级实时预览最多 384 像素；原尺寸细节应检查导出文件，不能把画布放大当成未提供的原尺寸实时渲染。
