# 照影的界面与使用流程

照影（PortraitLab）的界面围绕两类任务组织：修片调整已有像素，光影重塑生成新照片。中文名称用于软件显示，英文仓库名和 `PortraitLab.exe` 保持兼容。

## 常用操作

1. 选择修片或光影重塑，当前模块保持高亮。
2. 在当前模块导入照片，也可拖入文件或文件夹。照片库选择与光影输入列表分别标明，连续添加不覆盖之前的输入。
3. 修片单击预设只修改当前照片，可调整整体强度，展开手动参数。自定义预设只保存数值，不包含照片或笔刷。
4. 光影方案先填写方向、提示词和重绘程度；设备与尺寸保持用户选择。提交生成是独立动作，完成后保存为新照片。
5. 右侧效果对照显示原图与处理后；大图显示模式在同一区域。生成照片的对照使用提交时快照与对应裁切，避免不同构图造成误判。
6. 批量同步明确显示张数，保留各张笔刷，并可撤销上一次批量操作。后续编辑冲突时拒绝覆盖。
7. 导出前明确数量和格式；导入未完成时禁止开始导出。关闭桌面窗口前等待尚未保存的参数写入。

## 可用性验收原则

- 功能按钮使用明确中文，装饰性命名不替代操作说明。
- 主要说明和操作文字至少 12 CSS 像素；主要按钮至少 32 CSS 像素高，键盘焦点可见。小窗口以滚动和折叠容纳内容。
- 检查 1366×768 及相近高缩放可用区域，不能横向裁掉导入、模块切换或提交入口。原生窗口大小限制在当前屏幕工作区内。
- 反馈说明对哪张照片执行什么操作，以及是否涉及批量；成功状态不会假装预览已经完成。
- 未下载、已下载、校验中、已就绪、失败各有对应文案与动作。不可用操作同时解释原因。
- 经典 CPU/GPU 偏好、硬件可用性和实际执行设备分别处理。GPU 回退后显示实际 CPU，生成式设备另行配置。
- 输入为空、处理中、失败、重复导入、连续切换照片、误触恢复和退出都是正常使用场景，需要检查。

这些是设计与验证准则，不等于已经完成专业无障碍认证或多人可用性实验。当前预览长边最多 1600 像素；原尺寸细节应检查导出文件，不能把画布放大当成未提供的原尺寸实时渲染。
