# IC-Light 生成式重打光

PortraitLab 0.2 接入 IC-Light 的前景条件模型。它根据照片、文字和方向条件生成新的照明效果；经典修肤与径向曝光仍可独立使用。

## 在 Windows 中使用

便携版通过 `PortraitLab.exe` 启动服务并打开工作台，不要求用户另装 Python。软件可放在用户选择的盘符及中文路径；默认将数据、模型和缓存保存在便携目录的 `Data` 与 `Cache` 中。也可配置这些位置。`PORTRAITLAB_STORAGE_ROOT` 是用户主动启用的写入根限制，不是固定盘符要求。

首次使用先准备模型。准备流程从固定来源下载 IC-Light checkpoint、基座和所需分割模型，并校验模型清单；已有且校验通过的模型可复用。下载体积、磁盘余量与模型状态以实际准备界面为准。安装依赖和准备模型需要联网；推理使用本地照片和已准备模型。

选一张照片，设置生成尺寸和光线描述后创建任务；输入是创建任务时的当前修肤快照。需要以原始视觉结果生成时，先选原图预设，再创建任务。原图与生成结果分别保留。先用较小尺寸验看脸部、头发与背景，再决定是否增加尺寸或继续处理。

首批便携版验证面向 Windows x64。NVIDIA 8 GB、约 512 级别尺寸与低显存模式是兼容目标，12 GB 或以上为建议配置；这不是已经覆盖全部显卡和驱动的最低配置保证。当前主要实测设备为 RTX 5060 Ti 16 GB，具体通过的尺寸和速度以验证记录为准。CPU 已完成 256×256 小图验证，更大尺寸的体验尚未验证；AMD／Intel GPU 加速尚未接入。其他平台尚未完成同等打包与运行验证。

## 已完成的运行检查

2026-11-13，在 RTX 5060 Ti 16 GB 上完成以下真实模型推理：

| 生成尺寸 | steps | 显存模式 | worker 总耗时 | 峰值 allocated | 峰值 reserved |
|---|---:|---|---:|---:|---:|
| 512×768 | 20 | 低显存，组件交替驻留 GPU | 49.62 s | 2.28 GiB | 2.60 GiB |
| 512×512 | 10 | 模型常驻 GPU | 30.97 s | 2.62 GiB | 3.21 GiB |

耗时为单次 worker 记录，包含模型校验、导入／加载、推理和 PNG 写盘，不含依赖安装与首次模型下载。allocated／reserved 为 PyTorch CUDA allocator 的峰值，不是系统报告的全部显存占用或最低硬件要求。两行的尺寸、步数不同，不能据此单独量化低显存模式的速度差异。

两组 CUDA 结果来自同一张 16 GB 显卡，尚未验证 8 GB 实机。CPU 另在 Intel Core i7-11700 上完成 256×256、10 步、方向 left、float32、关闭低显存模式的真实推理，worker 总耗时 36.71 s（PyTorch 2.7.1+cu128 的 CPU 路径）。此 CPU 记录仅覆盖 256 小图，不推断 512／768 尺寸的使用体验。中文模型路径下的 CLIP／VAE／UNet／FC 加载和中文路径 PNG 写入也已通过；更多环境与验证记录由主验证文档维护。
## 参数与生成范围

| 参数 | 范围／含义 |
|---|---|
| `prompt` / `negative_prompt` | 希望得到或避免的光照与画面特征；提示词也可能改变内容 |
| `direction` | `none`、`left`、`right`、`top`、`bottom`；控制初始潜变量的渐变方向 |
| `seed` | 随机种子；便于记录配置，不保证跨硬件／依赖版本完全相同 |
| `steps` | 10–50；影响扩散计算量 |
| `cfg` | 1–10；文字条件引导强度 |
| `denoise` | 0.1–0.9；第二阶段重绘强度，较强时细节变化可能更大 |
| `width` / `height` | 每边 256–1024，必须为 64 的倍数；实际能否运行还取决于显存和参数 |
| `low_vram` | 省显存运行路径；用时间与数据搬运换取较低显存占用 |

照片和前景掩膜会同步缩放并中心裁切到请求比例。输出严格采用指定生成宽高，**不是原片全尺寸重建**。选择与原片接近的比例可减少边缘内容被裁切，但不提供构图完全不变的保证。

算法采用官方的 8 通道 UNet offset 合并、前景条件和两阶段扩散；方向是渐变初始潜变量，不是物理光源坐标。第二阶段倍率为 1，仍会重新扩散。前景以中性灰背景提供条件，模型生成整张新图；不会把生成结果自动限制在前景内或按掩膜贴回原图。

经典保护笔刷不直接保护生成图的相同位置；它只通过任务采用的当前修肤快照间接影响生成。应分别检查身份细节、眼睛、皮肤纹理、头发、饰物及背景；原片继续保留。
