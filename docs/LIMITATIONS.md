# 已知限制

- 本版是本机研究工具；没有完成跨肤色、年龄、妆容、遮挡和多种相机条件的系统质量评测。默认参数不能替代逐张验片。
- 人脸或皮肤误判会影响修肤范围。侧脸、远景小脸、浓妆、眼镜、胡须、低照度和彩色灯光尤其需要检查。无人脸时跳过人脸修肤和局部修光。
- `classic` 是非生成式修肤；纹理平滑、去瑕疵与匀肤仍可能削弱真实皮肤细节。保护笔刷限制修肤和局部曝光，不能冻结全局色彩变化。
- 局部修光是二维径向曝光，不是三维重布光，不可据此声称达到 IC-Light、质镜或摄影灯重布光的同等能力。
- 本版以 8-bit RGB 工作，导入单帧 PNG／JPEG／TIFF／WebP；不支持 RAW、动画或多页文件。输入经 EXIF 转正和 ICC 到 sRGB 转换；PNG／JPEG／TIFF 导出均为 8-bit sRGB，不继承上游 16-bit TIFF 能力，不复制 EXIF。原始文件副本单独保留。
- 同步数值不能保证不同照片观感一致；光比、肤色、主体大小和背景不同会改变效果。预览还受缩放、显示器与浏览器色彩管理影响。
- 本版没有 IC-Light、LBM、ModelScope 神经修肤后端；模型清单中的 planned 项不参与当前处理。
- 源码许可不替代模型、测试照片和第三方素材的许可。具体模型权重授权尚未独立确认的条目，保持该状态，不以框架许可证推定。
- 当前锁定 MediaPipe 0.10.21；2026-11-13 两张真实样片的分析、渲染和关闭日志未出现 Clearcut 信息。初次试用 0.10.35 时出现 `portable_clearcut_uploader.cc:90` 的 `Failed to send to clearcut` / `Status_ConnectFailed:12029`，只证明当时有失败的发送尝试，不证明发送内容包含照片。当前未做网络抓包，日志及二进制字符串辅助检查不能证明 SDK 完全离线；隐藏日志也不等于关闭网络行为。
- 程序限定本机回环服务和 F 盘数据路径。它不是多人服务器，也没有对互联网部署作安全保证。应用自己的路径限制不会迁移操作系统或浏览器自身存储。

性能与测试结论必须注明软件版本、输入尺寸、机器、参数、预览／导出模式，以及是否包含首次模型加载；不引用其他项目的演示速度作为本版实测速度。
