# 已知限制

## 图像与修肤

- 本版尚未完成跨肤色、年龄、妆容、遮挡和多种相机条件的系统质量评估。默认参数不能替代逐张验片。
- 人脸或皮肤误判会影响修肤范围。侧脸、小脸、浓妆、眼镜、胡须、低照度和彩色灯光需要检查。无人脸时经典引擎跳过依赖人脸的修肤与局部曝光。
- `classic` 为非生成式处理，但平滑、去瑕疵与匀肤仍可能削弱雀斑和真实细节。保护笔刷限制经典修肤与局部径向曝光，不冻结全局色彩。
- 经典引擎的局部曝光是二维径向调整，不能移动硬阴影或恢复被剪切的高光。它与 IC-Light 扩散生成是不同的处理路径。
- 工作与导出采用 8-bit sRGB。导入限单帧 PNG／JPEG／TIFF／WebP，经 EXIF 转正和 ICC 转换；不支持 RAW、动画或多页文件。PNG／JPEG／TIFF 导出不复制 EXIF，原始副本另行保留。
- 同步数值不保证不同照片的观感一致，预览也受缩放与显示器色彩管理影响。

## IC-Light 生成结果

- IC-Light 会生成新像素，可能改变身份细节、脸型、皮肤纹理、衣服、饰物和背景。前景条件与固定 seed 都不是逐像素保真或身份保证。
- 方向选项控制渐变初始潜变量，不是三维光源位置、测光值或精确阴影角度。生成结果不能替代物理光照测量。
- 扩散计算在指定生成尺寸进行。即使随后放大或融回较大照片，也不等于原图分辨率的真实细节重建；应检查最终输出尺寸及生成元数据。
- MediaPipe 前景掩膜与官方 BRIA 演示不同，头发、透明物体、遮挡和复杂背景可能产生边缘异常。没有把替换分割器后的质量视为与官方演示完全一致。
- CUDA 推理依赖兼容的 NVIDIA 显卡、驱动与实际运行库。8 GB／512 级别低显存运行是兼容目标，12 GB 或以上为建议；目前主要实测为 RTX 5060 Ti 16 GB。AMD／Intel GPU 加速未接入；CPU仅验证 i7-11700 上的 256×256、10 步小图，不代表较大尺寸已验证。可运行尺寸与耗时以实际验证为准，不把一种设备的成功外推到所有配置。
- 本版没有 ModelScope、LBM、IC-Light 背景条件 FBC 或其他未列出的神经修肤后端。IC-Light 的 FC checkpoint 不能被描述为质镜私有生成器的复现。

## 许可、网络与本机环境

- 代码、IC-Light 权重、基座权重和照片的条款分别适用；OpenRAIL 的使用限制不会因本程序采用 AGPL 而消失。完整条款见 [RELIGHTING.md](RELIGHTING.md) 及随附 licenses。
- MediaPipe 具体权重许可尚未独立确认的条目继续保留该状态，不以框架许可证推定。
- 首次依赖安装和模型准备需要联网；本地推理不等于已经证明全部第三方库完全不联网。应用本身不提供照片上传服务。
- 当前经典环境固定 MediaPipe 0.10.21。已记录样片流程未出现 Clearcut 日志；初次试用 0.10.35 曾出现发送失败日志，只证明当时的失败尝试，不证明其内容包含照片。未做完整抓包，隐藏日志也不等于禁用网络。
- 服务限本机回环，软件可安装于用户选择的盘符与中文路径，Data／Cache 可配置；`PORTRAITLAB_STORAGE_ROOT` 仅用于用户主动限制写入根。首批验证面向 Windows x64，其他平台尚未完成同等验证。便携目录设置不会迁移既有系统或浏览器存储，也不是互联网多人部署方案。

性能记录必须注明模型与依赖版本、输入／生成尺寸、设备、参数、首次加载是否计入，以及是否包含写盘；不把少量样片或上游演示当作全面质量保证。
