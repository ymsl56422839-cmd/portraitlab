# 照影 0.4.1 小补丁

0.4.1 在 0.4.0 上增加局部修片和常用操作，不更换运行时与模型。**已有 0.4.0 完整包只需本次 Upgrade 小补丁；新用户只需 0.4.0 完整包加小补丁。此次不重新分发大运行时包。**

## 本次变化

- **矩形局部调整：**每张照片保存一处矩形，可绘制、移动、缩放、重画、删除与撤销。局部参数在全局修片后追加，边缘向内羽化。完成选区保留效果，全局与局部参数分别保存；批量只复制全局参数。
- **四类 52 个预设：**通用 26、长者人像 8、成人人像 10、少年人像 8。四个入口常驻，另保留用途筛选、收藏、搜索与自定义。原 22 个 ID、数值参数和收藏兼容；类别由用户选择，不识别年龄。长者方案默认关闭磨皮、纹理柔化和去痘。
- **独立去痘强度：**复用固定 RapidRetouch 的斑点检测和分频修补算法，不要求新模型，也不依靠增加磨皮。强度控制已检测痘点的修复量，可配合矩形与保护笔刷。
- **模型入口增强：**照片库下方常驻“模型下载与设备”，分别显示基础处理和布光分析模型的状态及对应操作；已有模型可直接校验。
- **悬停 V 轮换：**鼠标停在图像视窗时，按 V 依次切换原图、滑动对比、处理结果。双视图各自切换；输入文字、弹窗和拖动时不触发。

## 安装小补丁

1. 准备已完整解压的 0.4.0 Windows x64 软件目录，保留原有 Core 和全部 AI 运行组件。
2. 在每个窗口保留或放弃布光草稿，停止处理与模型下载，关闭所有照影窗口。建议先备份 `Data`。
3. 将 0.4.1 Upgrade ZIP 的**全部内容**解压到原软件目录，与 `PortraitLab.exe` 同级，选择覆盖程序文件。ZIP 没有额外的顶层文件夹，不要在原目录内再建一层软件目录。
4. 重新启动。照片、编辑参数、自定义预设、收藏和模型继续使用原 `Data`；`runtime`、`AI` 和 `Cache` 不由补丁覆盖。

补丁不含运行时或模型，不能单独作为完整安装，也不能只复制 EXE。若提示更新未生效，关闭全部窗口再启动，避免复用旧后台。升级清单另列 0.2.0／0.3.0 为兼容运行时基线；本次主要验收路径为 0.4.0。

## 处理边界与兼容性

去痘目前只修复识别到的独立面部痘点。连片红痕、痘坑或低对比斑点可能漏检，雀斑可能误判；“全身皮肤”不会额外对身体去痘。建议放大检查，并用保护笔刷保留痣、雀斑和妆面。不保证逐点识别或纹理完全不变。

矩形外保留的是本次全局修片底图，不能撤回原有全局调整；后续布光与有损 JPEG 编码仍可能改变像素。目前每张照片仅有一处矩形，不是多图层局部蒙版工具。

旧参数新增的 `acne` 默认零，原 22 个配方数值保持。新版预览改由原尺寸统一底图缩小，旧缓存会按处理签名重算；可能与旧版直接缩图修片存在细节差异，不能把参数兼容解释为旧预览逐像素不变。无损 PNG 可用于范围与像素检查。
