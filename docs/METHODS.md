# 方法与处理范围

PortraitLab 0.4.1 的主界面包含经典修片与原片交互布光：`classic` 对已有像素执行修肤、去痘、色彩与局部曝光；交互布光使用估计几何和确定性光照公式。旧 IC-Light 生成式后端仅保留历史兼容，其输出性质不同，不能与当前布光流程混为一谈。

## 经典区域分析

MediaPipe Face Landmarker 提供关键点，Selfie Multiclass Segmentation 估计背景、头发、身体皮肤、面部皮肤、衣服与配饰。分析采用缩小图像以控制开销，结合关键点、肤色样本与五官／须发排除规则形成修肤区域。模型标签不是准确像素标注，细边缘与遮挡需检查。Windows 中文模型路径由 Python 读取为字节，再通过 MediaPipe 的 `model_asset_buffer` 加载；这是对两份上游适配器的路径兼容修改，不改变模型权重或区域分析算法。

## 修肤与色彩

修肤复用 RapidRetouch 的 `skin` 及必要依赖：分频、边缘感知平滑、局部瑕疵判断、匀肤和纹理／毛孔柔化，作用范围由皮肤掩膜决定。`texture` 表示纹理柔化，不是补画毛孔或增加真实细节。雀斑、妆容与细发也可能受到影响。

全局曝光、暖冷与饱和度由集成层应用。曝光与暖冷增益在线性光中计算，再返回 sRGB 编码。整体处理强度混合经典处理结果与原图；经典导出使用原尺寸工作图。

0.4.1 提供 52 个具名参数组合：通用 26、长者人像 8、成人人像 10、少年人像 8。四组仅是用户手动选择的配方分类，不调用年龄识别。原 22 个 ID 和数值保持不变，新增 `acne` 默认为零；长者组默认关闭柔肤、瑕疵淡化、纹理柔化与去痘。配方从零修肤基线建立，只有明确列出的项目才启用；黑白方案使用零饱和度和完整混合。

自定义预设保存当前编辑范围的参数，不保存矩形位置或笔刷。收藏与批量撤销保存在本地状态中。批量只复制全局参数，保留各张照片的局部调整与保护笔刷；撤销先检查当前全局参数仍匹配该次操作，遇到冲突拒绝整个恢复请求，不覆盖随后编辑。

可选 GPU 合成通过独立 AI Python 环境中的持久 Torch worker 执行。线性曝光、局部曝光乘场、冷暖、饱和度、整体混合和 sRGB 编码在 CUDA 上分块计算；人脸分析、修肤、去痘以及 PNG／JPEG 压缩仍由 CPU 执行。核心环境不导入 Torch。自动模式遇到不可用设备可回退 CPU，并返回实际设备和原因；显式 CUDA 失败则报错。布光分析设备单独选择。

## 独立去痘

`acne` 与 `blemishes`、`smooth` 分开。前者接入固定上游的 `acne_spots`／`_heal_acne`：比较皮肤与邻域的明暗和偏红程度，寻找尺寸合适、紧凑独立的斑点，排除疑似痣、线状阴影及五官边缘；分离宽尺度色调和细纹理，以 Telea inpaint 修补色调后回加纹理。已有 `blemishes` 继续用于小瑕疵和较粗毛孔的邻域色调补偿，`smooth` 继续是柔肤。

上游参数控制候选检测敏感度；本集成将其固定为 `0.5`，先计算单独去痘结果，再按公开 `acne` 的 `0…1` 值混合修复差值。因此调节强度不会扩大检测范围，也不需要新模型。去痘目前只处理面部皮肤；“全身皮肤”模式不会额外对身体去痘。连片红痕、痘坑、低对比斑点可能漏检，雀斑和妆容可能误判，不作医疗分类、纹理保真或逐点识别保证。

## 矩形局部调整与统一底图

每张照片可保存一处矩形，位置和大小按原图坐标归一化。先执行全局修片，再以独立中性参数执行局部附加处理；计算时保留全图上下文，仅将结果混入矩形内部。边缘向内羽化，宽度为图像短边的 1%，上限 32 像素；矩形外保留全局修片底图的像素值。该保证不包含后续布光与有损 JPEG 编码，也不表示撤销原有全局调整。

修肤和面部曝光仍受自动皮肤选区及已有保护笔刷约束；局部曝光、冷暖与饱和度则限定在矩形。全局和局部参数分别保存，局部编辑时禁止批量及保护笔刷操作，避免混淆作用范围。矩形可以移动、缩放、重画、删除或撤销；完成选区仅退出编辑，保留效果。

修片预览和保存从原尺寸统一底图缩小，导出复用相同全局／局部参数。缓存键包含引擎签名、照片、全局与局部参数及笔刷；旧缓存按新版签名失效。旧版直接在缩图上处理与新版原尺寸处理后缩图存在细节差异，不能由“旧参数兼容”推断“旧预览逐像素不变”。

## 经典局部曝光与笔刷

椭圆径向权重控制人脸附近的局部曝光，并向边缘平滑衰减。它没有估计三维法线、反射属性或物理光源，不能移动硬阴影或恢复被剪切的高光。

保护笔刷从自动皮肤掩膜中减去处理权重；恢复笔刷只恢复该处原先的自动区域。笔刷限制经典修肤、去痘与面部径向曝光，不限制全局曝光、暖冷、饱和度。批量同步只复制全局数值参数，各张照片分别分析并保留各自笔刷与矩形；经典导出记录这些快照。

## 交互布光

Depth Anything V2 Small 估计深度后，交互光源按当前主体／背景／全图范围调整修片底图。全局和矩形修片先完成，再应用保存的布光参数。方法、来源与近似边界见 [INTERACTIVE_LIGHTING.md](INTERACTIVE_LIGHTING.md)。

## IC-Light 生成式重打光（旧后端）

采用官方前景条件 `iclight_sd15_fc.safetensors`，配合官方演示使用的 Realistic Vision V5.1 基座。适配保留 8 通道 UNet 输入、基座权重与 IC-Light offset 合并、DPM++ 2M SDE Karras 调度器，以及两阶段扩散。

MediaPipe 的 `1 − 背景概率` 提供前景条件；输入前景以 127 中性灰作为背景。没有引入官方演示的 BRIA RMBG-1.4。前景掩膜用于向模型提供条件，**不是把输出限制在该区域内的局部编辑蒙版**。

输入图与前景掩膜同步缩放、中心裁切到请求宽高比。方向选项以渐变图初始化潜变量；`none` 不施加该方向初始化。第二阶段继续扩散，`denoise` 控制这一阶段的重绘程度。高分辨率倍率固定为 1，因此最终生成尺寸就是请求的宽高；这不等于只运行一阶段，也不等于保留原图分辨率。

结果是一张完整的新生成图，不按皮肤或前景掩膜贴回原片。IC-Light 使用创建任务时的当前修肤快照；需要原始视觉结果时可先选原图预设。经典保护笔刷不直接约束 IC-Light，只通过这张输入快照间接影响生成。模型仍可能修改身份细节、纹理、衣服及背景。

参数、硬件与模型条款见 [RELIGHTING.md](RELIGHTING.md)。ModelScope 和 LBM 仍未集成，不能从研究候选条目推断为可用后端。
