# 修补笔刷与面部塑形

0.6.0-dev 为本地测试版，未打包或发布。本次增加局部修补和二维脸型调整，不包含新的神经修肤模型；原有模型及运行时继续使用。

## 修补笔刷

在修片模块右栏选择“修补笔刷”，选择方式后点击“开始修补”，在处理结果视窗点按或拖动。每次按下至松开是一笔；松开后计算并更新预览，拖动中的笔迹只是作用范围提示。可以放大画布再操作。

- **自动修补**：在附近寻找纹理与明暗相近的供体。没有可信供体时保留原貌并说明原因，不强行填充。
- **取样修补**：先点干净纹理，再涂抹目标；Alt 点击或“选取样本”可更换供体。供体与目标保持相对位移。
- **恢复修补前**：涂抹恢复该处修补层输入；保留之前的全局修肤、色彩、矩形局部调整。
- **半径／柔边／强度**：半径按原片短边计算，默认 0.4%；UI 显示对应原片像素。柔边只改变边缘过渡。单笔自交、回描不会反复叠加强度，多笔则按顺序叠加。
- **撤销上一笔／清除全部修补**：只移除修补记录。工具以外的“撤销”恢复完整编辑快照。Esc 取消正在画的一笔；没有正在画的笔迹时退出工具。

每图最多 100 笔，每笔最多 1,000 个采样点，合计最多 16,384 点。旧六字段点修记录继续兼容。工具使用修补层输入的真实纹理，不把已经修过的区域递归当作新供体。供体匹配不理解痣、雀斑或痘痘的语义，须由用户确认目标；大面积遮挡、皮肤结构缺失不适合这个工具。

## 面部塑形

在右栏选择独立“面部塑形”页，从“调整人物”选择目标，画布轮廓用于核对人物。检测可能漏检或误检，不自动决定要调整谁。右栏的“基础调整、修补笔刷、面部塑形”切换不会清除编辑记录；当前工具独占操作区，避免其他参数挤占空间。

提供脸宽、颧骨宽度、下颌宽度、下巴长度和下巴宽度。初始值均为 0，正值加宽／加长，负值收窄／缩短。前三项支持左右联动、画面左侧、画面右侧；这里的左右按照片画面定义。每项有“复位”，另有“重置全部塑形”。切换联动模式本身不会修改数值。

“局部推移”用于在画布拖动轮廓，松开后更新；单笔位移有上限，需要更多变化时分次轻推。“局部恢复”在落笔位置恢复局部原有形状，强度决定恢复比例。“撤销上一笔”撤销手动塑形，顶部“撤销”也可撤回参数调整。手动工具不依赖人脸检测，最多保留 128 笔。

这是局部二维像素变形，不是三维重建。轮廓附近的发丝、耳饰、衣服和背景也可能随动，尤其是较大调整，需在放大和原图对比下检查。参数塑形需要现有 MediaPipe 关键点模型；手动推移、修补和图像变形使用 CPU，无需新增权重或 NVIDIA 显卡。

## 坐标、保存与布光

处理顺序固定为：原片 → 全局修肤／明暗／色彩 → 矩形局部调整 → 修补笔刷 → 面部塑形 → 交互布光。

修补路径、保护笔迹和矩形一直以原片坐标保存。已塑形画面上的落笔先反变换至原片坐标；工具轮廓再映射回显示坐标。因此调整脸宽后，已有修补、选区和保护位置一起跟随。正在计算或结果图尚未加载时暂时锁住坐标工具，防止在旧画面上使用新坐标。原图视窗显示未经塑形的原片，编辑工具作用于处理结果视窗。

预览与原尺寸导出复用相同处理底图。缩小预览使用面积重采样，不保证屏幕缩放后的每个视觉细节等同原尺寸显示。塑形一次合成坐标后采样，避免每条记录都重复插值原图。布光的法线、深度和主体选区也用同一坐标变换，再归一化法线向量；这是估计几何的位置映射，不是重新计算真实三维几何。

记录随照片保存，重启继续；导出参数 JSON 包含修补和塑形。重置修片预设、切换色调、批量同步参数不会复制或清除每张图自己的塑形与修补。移除照片沿用照片库的可撤销行为，不删除外部原片。
