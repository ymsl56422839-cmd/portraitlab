# 照影 0.7.0

0.7.0 将重建后的 V2 编辑器作为独立 Windows 分享包提供。模型、Python 推理环境、桌面界面运行组件与许可说明随包提供；完整解压后运行 `PortraitLab.exe`，无需另装 Python、Git 或手动放置模型。旧版程序与已有照片资料不需要覆盖。

## 本次功能

- 中央原尺寸分块画布支持单视图、双视图、滚轮与滑块缩放、平移，以及各视图独立的原图、滑动对比、处理结果。鼠标所在视图按 `V` 轮换显示。
- 修片分为肤质色彩与瑕疵修补。ModelScope 专项模型提供候选和修补内容；候选默认不勾选，支持手动标记、逐处恢复、撤销与重做。
- 局部框选、保护笔刷与分层强度控制限定调整范围。塑形提供左右独立参数、轮廓推拉、固定区域与局部恢复；普通预设不自动改变脸型。
- 通用、长者、成人、少年四类共 32 个修片预设，支持强度调整、搜索和照片多选套用；年龄分类由使用者选择。
- 光影提供主体、背景独立布光，方向光、点光源、聚光灯、柔光面光源四种类型和 12 个起点预设，支持画布拖动光源。
- 调整通过草稿、保留与取消控制；照片库支持删除，工具提供明确的准备、处理中、已更新与失败状态。保留结果可导出为原尺寸 PNG。
- “模型与计算设备”集中显示模型状态和 CPU / NVIDIA GPU 选择。模型随包固定版本并校验 SHA-256，处理照片时不需要下载权重。

## 验证与边界

V2 与分享构建器回归已通过 185 项测试；保留的旧版源码回归通过 430 项、跳过 5 项。此前另通过 40 项浏览器模拟检查、16 项真实流程检查、6 项光源拖动检查与 17 项部署后冒烟检查。真实 CPU 神经修肤推理已经运行，与本机 CUDA 输出比较仅有 1 个像素的单通道相差 1/255，候选蒙版一致。这些是记录的实现检查，不代表所有硬件或所有人像画质均已验收；发布包的文件、启动及解压验证另由发布流程执行。

当前只有一张独立用户原片用于完整真实照片验证，没有同一原片的质镜成片，不声称画质已达到或超过质镜。尚未在另一台无开发环境的独立电脑完成验收，也未测出最低显卡门槛。CPU 可运行，GPU 推理需要兼容的 NVIDIA 显卡和驱动；GPU 加速不表示全部图像合成均由 GPU 执行。

光影采用单张照片的相对深度与近似法线，不能可靠消除原有阴影、恢复真实材质或生成准确投影。交互预览与全精度检查有不同的计算代价；保留和导出前应查看最终结果。塑形是二维局部变形，附近头发、饰品与背景可能受影响。

输入/输出目前为 8 位 sRGB，处理内部使用 float32 线性光；这不是 RAW 显影或 HDR/16 位工作流。皮肤分析可能误判痣、雀斑、妆容与背景图案，请确认人物和修补位置。
