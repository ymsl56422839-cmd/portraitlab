# 复现与发布检查

## 软件与数据位置

首批便携包面向 Windows x64，入口为 `PortraitLab.exe`；包内包含运行环境，无需系统 Python。软件可放在用户选择的盘符和中文目录，默认 `Data` 保存照片、参数、模型与结果，`Cache` 保存可重建缓存。位置可配置；如用户希望主动限制写入范围，可设置 `PORTRAITLAB_STORAGE_ROOT`。开发本版时使用的工作盘符不是公开软件的安装要求。

源码启动与构建命令以根 README 和各启动脚本为准。保留根 `LICENSE`、`THIRD_PARTY_NOTICES.md`、`licenses` 及 `portraitlab/vendor`；不要只复制应用脚本而遗漏对应源码或第三方条款。

经典环境的锁定依赖见 `requirements.lock.txt`；生成环境的直接版本见 `requirements-relight.txt`，完整解析版本见 `requirements-relight.lock.txt`。两个环境分别复现，不把任意最新依赖当作同一验证环境。便携包中的 core 与 AI 解释器也应分别记录版本和架构。

## 模型准备

1. 核对经典模型清单和重打光清单，记录 repo、固定 revision、文件路径与期望 SHA-256。
2. 保留完整模型条款和卡片；IC-Light 代码、checkpoint、基座、分割模型分别记录，不能用 AGPL 或 Apache 框架许可代替权重许可。
3. 使用显式模型准备流程下载至配置的数据目录；校验已有文件后再复用。准备失败和模型推理失败分别报告，不以下载完成表示可运行。
4. 留存准备记录，但不把含本机个人路径的运行记录或模型二进制放入公开源码仓库。

## 经典引擎与既有验证

2026-11-13 的 0.1.0 记录使用 MediaPipe 0.10.21、NumPy 1.26.4、OpenCV 4.11.0.86、SciPy 1.15.3；其 12 项引擎测试和真实样片结果见验证记录。这是经典引擎的历史证据，不作为新增 IC-Light 推理已经通过的证据。

同次 MediaPipe 0.10.21 样片流程未观察到初次试用 0.10.35 时的 Clearcut 发送失败日志；未做完整网络抓包，不据日志或二进制字符串检查保证零联网。

## IC-Light 复现实验

记录输入 SHA-256 与原始尺寸、中心裁切后的生成尺寸、前景掩膜来源、完整提示词、方向、seed、steps、CFG、第二阶段 denoise、低显存开关、模型文件 SHA、Python/PyTorch/CUDA/驱动版本和设备。分别记录首次加载、采样、写盘耗时及峰值内存／显存，不能把热启动与首次加载混为一谈。

本版硬件目标为 NVIDIA 8 GB、512 级别尺寸配合低显存模式，建议 12 GB 或以上；RTX 5060 Ti 16 GB 的实测不能证明全部 8 GB 设备兼容。CPU、不同 GPU、不同驱动与大尺寸都应单独验证。AMD／Intel GPU 加速未接入；其他操作系统尚未完成同等便携验证。

固定 seed 不保证跨硬件完全相同。检查实际生成文件尺寸、脸部与服饰变化、前景边缘、中心裁切和原图保留情况；生成图不是精确身份或物理照明测量。测试采用有权处理的照片，私有样片和含人像截图不随公开仓库发布。

## 测试与发布

运行仓库提供的测试，并记录命令、依赖版本、通过／失败数和未覆盖项。安装完成不代表测试通过，单元测试也不能替代真实模型与实际 Windows 启动验证。最新事实以 `docs/VALIDATION.md` 和本次发布记录为准。

源码发布保留 AGPL 条款、版权、变更说明和全部必要第三方原文。二进制发布提供对应源码与构建步骤，保留 Python、实际 Python 包及 GPU 运行库的许可证／NOTICE；依赖名称或版本清单不是许可证集合。模型若随包分发，另附其完整条款、卡片、来源及使用限制。默认公开包可通过单独下载模型控制体积。

打包前实际检查文件内容，排除上传／导入副本、测试照片、生成图、人像截图、凭据、会话数据、私人路径日志与缓存。`.gitignore` 只辅助源码管理，不保证 ZIP 自动排除这些内容。对源码和便携附件分别计算 SHA-256，并验证解压后的启动与模型准备流程。
