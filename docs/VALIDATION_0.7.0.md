## 分享包启动与退出

使用分享包自身的 Python、应用代码、模型路径及固定版 WebView2 157.0.4341.60 验证，测试资料与缓存独立于发行包。

- 无界面服务启动通过；遇到已占用端口会选择下一端口。
- 中文和空格资料目录、缓存目录可用。
- 再次启动同一资料目录不会增加第二个服务实例。
- 通过本地接口正常关闭后，服务退出，监听端口释放。
- 内置桌面界面加载完成，原生消息桥接及关闭前保存接口可用。
- 异步保存完成前会等待；保存失败、尚未修补的手动标记、正在导入照片时均阻止退出。测试临时状态在结束后恢复。
- 本地来源、端口与外部链接策略验证通过，拒绝文件协议、命令协议和伪装的本地主机地址。
- 浏览器资料及错误报告目录位于指定缓存目录内。隐藏测试检查随包组件许可原文，不写入用户同意记录。

首次在受限自动化环境中运行内置浏览器时，其 GPU 与渲染子进程遇到访问拒绝。相同分享包在正常 Windows 用户进程环境中复测通过。发布程序保留 WebView2 的安全隔离，没有加入关闭浏览器沙箱的参数。

## 包内模型与图像处理

使用发行包中的运行环境和模型完成 18 项真实图像验收，包括：

- 所需模型检查、GPU 均肤、深度分析，以及 CPU 均肤。
- 手动修补产生 311 个变化像素；标记区域外变化像素为 0。
- 组合调整的预览、保留结果与导出图像逐像素一致。
- 恢复原图及撤销操作。

该组验收使用一张获准测试的原片及其约 368 万像素裁切图。裁切图属于同一图像来源，不计作独立样本。这些结果证明已测流程在该样本上可运行且输出一致，不能据此认定所有人像类型均达到相同画质。

## 结果的适用范围

本次验证包含完整包的实际启动和处理，不只检查模型文件是否存在。尚未覆盖所有 Windows 版本、显卡型号、驱动版本和不同拍摄条件；其他设备与更多独立照片仍需持续回归。开源代码、模型与第三方运行组件各自的许可见随包许可资料及项目说明。
