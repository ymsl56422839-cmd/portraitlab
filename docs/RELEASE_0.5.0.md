# 照影 0.5.0：按组预设与取样点修

0.5.0 更新修片操作和计算顺序，沿用已有运行时与模型。新照片默认从原图的中性修片效果开始；预设不再无提示地整套替换其他处理组，并加入明确选择供体的局部点修。没有加入 ModelScope 神经修复模型或新的修肤权重下载。

## 主要变化

- **四类 53 个预设入口：**通用 27、长者 8、成人 10、少年 8。旧 52 个 ID 与收藏保留，新增自动平衡；四类是手动分类，不识别年龄。内置方案按修肤、明暗、色彩应用；暖色预设保留曝光，修肤预设保留色彩。旧自定义预设继续作为完整参数快照使用，并明确提示其替换范围。
- **按照片统计明暗：**标注自适应的预设测量原片或局部全局底图的亮度、面部亮度与高光余量，给出受限的曝光／补光量。这是可解释的数值计算，不是新神经模型或自动白平衡；缺少可用人脸、近黑和已过曝时有提示。
- **重置后可继续调整：**新导入默认中性参数；重置当前范围后总强度为 100%，下一次手动调整直接生效。独立点修与布光保留，使用各自撤销操作移除。
- **识别与强度分开：**“痘点识别”控制检测灵敏度，“去痘强度”控制已识别点的修复量；没有可修复点时明确提示，漏检可改用取样点修。
- **取样点修：**开始点修后，先点干净皮肤取样，再点瑕疵；Alt 点击重新取样，“撤销上一处”逐笔撤销。半径默认短边的 1.5%，界面支持 0.2%～5%，每张最多 100 处。供体真实纹理与目标周边色调结合，圆盘外保留点修底图；边缘和无有效像素有提示。
- **统一底图与冲突保护：**原片 → 全局修肤／明暗／色彩 → 局部增量 → 点修 → 交互布光。预览和导出复用同一全尺寸修片底图；点修进入独立缓存、保存记录及导出 sidecar。预设分析期间照片有更新时拒绝覆盖后续编辑。

取样点修改编自 Chris Cork 的固定版本 RapidRetouch Patch，遵循 **AGPL-3.0-only**，见[来源及修改说明](../licenses/SPOT_REPAIR_NOTICE.txt)。详细操作、参数和算法边界见[预设与点修管线](PRESET_PIPELINE.md)。

## 更新与旧数据

当前为本地测试版本，尚未生成或发布 0.5.0 Upgrade。此次验证使用已有完整便携程序及其运行时，完成源码同步；无需重新下载已经校验正确的模型。以下步骤供后续升级包使用，具体兼容范围以实际发布清单为准，升级包不能单独安装运行。

1. 保留或放弃所有布光草稿，停止处理和模型下载，关闭全部照影窗口；建议先备份 `Data`。
2. 将升级包全部内容放到原 `PortraitLab.exe` 同级目录，覆盖程序文件；保留 `runtime`、`AI`、`Data` 和 `Cache`。不要只换 EXE，也不要多套一层目录。
3. 重新打开。若提示新管线尚未生效，关闭全部窗口后重启，避免继续连接旧后台。

旧照片参数、保护笔刷、矩形局部调整、自定义快照与收藏保留。旧记录没有 `spot_repairs` 时使用空数组，没有 `acne_sensitivity` 时使用 `0.5`。升级不会自动重新应用内置预设；再次点击旧预设 ID 时使用新版按组操作。缓存重算及新操作语义可能使结果与历史预览不同，参数兼容不等于旧结果逐像素不变。

## 设备、精度与限制

原有 GPU 合成保留；修肤、痘点识别和取样点修仍由 CPU 计算。布光分析保持独立的 CPU／CUDA 选择。无需下载旧 IC-Light 扩散基座来使用这次新功能；已有 ModelScope 或其他外部模型也不会被该管线自动调用。

工作图与导出仍为 **8-bit sRGB**，处理阶段之间仍有量化，未升级为高精度或 RAW 管线。无损 PNG 可核对相同尺寸的预览与导出；缩放及 JPEG 压缩有各自差异。

自动检测可能漏掉连片红痕、痘坑或低对比斑点，也可能误判雀斑／妆面。点修需要合适的供体与目标，不保证身份特征或纹理完全不变。亮度统计不能恢复已丢失的过曝细节，也不能替代对高调、低调等拍摄意图的判断。
