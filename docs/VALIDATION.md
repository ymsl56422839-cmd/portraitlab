# 0.1.0 验证记录

日期：2026-11-13。运行于本次 Windows 工作站，Python 3.12.14 AMD64，CPU 推理。全部依赖见 `requirements.lock.txt`。

## 自动测试

- `python -B -m pytest -q`：**21 项通过**，约 2.75 秒。
- 12 项引擎检查覆盖参数、笔刷、无脸行为、线性曝光、零强度恒等与模型缺失处理。
- 9 项服务检查覆盖鉴权、Host/Origin、上传限额、原件保留、ICC、导出参数快照、任务取消、重启恢复、联合编辑事务和缓存版本失效。
- 测试框架发出一条 HTTPX 测试客户端弃用提示；未导致功能失败。

## 实际浏览器操作

使用 Microsoft Edge / Playwright，在本地服务上完成以下操作；浏览器配置与缓存保存在 F 盘：

1. 导入两张现有本地样片，实际运行 MediaPipe 识别。
2. 连续修改滑杆，检查参数写入与刷新后的恢复。
3. 绘制保护笔刷，并检查笔刷记录进入导出元数据。
4. 同步两张照片的参数，分别保留笔刷。
5. 批量导出两张原尺寸 PNG，附带 JSON 参数和来源记录。
6. 检查 1440×1000 与 1100×850 布局；无页面 JavaScript 错误。

浏览器检查使用真实服务、真实模型和真实文件输出。服务单元测试另使用可控替身，二者没有混称。
照片与含人像的截图只保存在私有本地工作区，不随仓库分发。

## 真实样片

| 输入 | 人脸数 | 分析 | 渲染 | 说明 |
|---|---:|---:|---:|---|
| 1783×2400 正面 | 1 | 1.20 s | 0.92 s | 固定 MediaPipe 0.10.21，面部处理 |
| 1920×2560 侧脸 | 1 | 0.96 s | 3.41 s | 面部＋身体处理 |
| 3840×5168 原片 | 1 | 2.98 s | 4.38 s | 分析含首次加载；PNG 写盘另计约 1.47 s |

3840×5168 测试的进程峰值工作集为 **2.30 GiB**，包含 Python、模型、原图与中间数组，不是 GPU 显存。
默认参数下，处理掩膜值 ≤ 1e-6 的 19,431,398 个像素逐像素保持不变。掩膜值 > 0.1 的区域平均变化约 0.64/255，说明默认效果保守，**不构成修图质量评分**。

上述是单机少量样片结果，不是通用性能或专业修图质量保证。尚未完成多人、重度痤疮、极端光线、各肤色和大批次长时间稳定性评测。
当前版本没有接入 ModelScope、IC-Light、LBM，也没有复现质镜的私有光场生成器。

## SDK 版本选择

最初测试 MediaPipe 0.10.35 时出现 Clearcut 发送失败日志。固定为 0.10.21 后，在上述推理与关闭流程的 stderr 中未再观察到该日志。
另做了指定二进制的相关字符串检查作为辅助证据；没有进行完整进程抓包，因此不将该结果解释为“已证明绝对零出网”。

## 复现边界

实际照片因许可未核明而不公开。其他人可以使用自己有权处理的照片执行相同步骤，结果会随照片、硬件而变化。
代码、模型固定 URL、期望 SHA-256、依赖版本、参数及算法来源随仓库提供；下载权重的许可单独说明。
