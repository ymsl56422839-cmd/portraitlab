# 照影 · PortraitLab

在本机修整人像照片的开源 Windows 软件。**0.7.0 全模型分享版**采用新编辑器：手动标记与神经修补、神经均肤、局部调整、面部塑形、主体／背景独立布光，以及原尺寸图块画布。

## 下载与启动

从 [0.7.0 下载页](https://github.com/ymsl56422839-cmd/portraitlab/releases/tag/v0.7.0) 下载该版本的**全部 Part ZIP**，把它们解压到同一个目录，合并同名的 `PortraitLab-0.7.0-Windows-All-in-One` 文件夹，然后双击 `PortraitLab.exe`。

每份都是普通 ZIP，无需拼接工具；它们是同一完整软件的组成部分，不能只下载一份。GitHub 单个资产有大小限制，因此分开上传。本地完整分享 ZIP 只需解压一次。

软件包包含 Python、PyTorch／CUDA 运行组件、固定版 WebView2、应用本地 VC 运行库，以及实际使用的五个模型文件。正常使用无需另装 Python、Git、CUDA Toolkit 或下载模型。显卡驱动属于操作系统环境，使用 NVIDIA GPU 仍需兼容驱动。请解压后运行，不能直接在压缩包预览中启动。

支持 Windows 10／11 x64 的可写本地目录，包括中文和空格路径；桌面窗口使用系统的 .NET Framework 4.6.2 或更新版本（现代 Windows 通常已具备）。不要放入系统保护目录、网络共享或路径过深的文件夹。照片副本、记录与缓存默认保存在软件目录。**这是独立新版本，勿覆盖旧包；旧版编辑记录不自动迁移。** 首次运行需阅读并接受随包第三方组件条款。详情见[分享与便携说明](docs/PORTABLE_0.7.0.md)。

## 编辑流程

1. 导入照片，或把照片文件拖进中央画布。
2. 右侧选择修片、塑形、光影或预设。人像专项首次使用需准备分析；顶部“模型与计算设备”可查看状态、校验文件、选择 CPU／NVIDIA GPU。
3. 调整后查看中央草稿。拖动时先显示交互预览，停手后细化原尺寸图块；当前画面载入完成才可点击“保留调整”。
4. 已保留结果可继续编辑、撤销／重做或导出。顶部“全部恢复原图”恢复当前照片的原始状态；照片库移除不删除外部原文件。

未处理的手动标记、未保留草稿和进行中的操作会阻止桌面窗口直接退出，并提示先处理，避免无声丢失工作。

| 功能 | 当前实现 |
|---|---|
| 瑕疵修补 | ModelScope 神经修补；自动候选默认不选，逐点人工确认；也可手动点按或涂抹标记 |
| 人像修片 | 神经均肤、质感柔肤、肤色、泛红、痘印色泽、眼周、反光、细纹和曝光色彩，共 17 项参数 |
| 局部与保护 | 独立矩形选区、羽化、保护笔刷及擦除保护 |
| 面部塑形 | 脸宽、面颊、下颌、下巴、额头；左右分别调整；推拉、局部恢复、固定范围 |
| 光影重塑 | 主体与背景独立灯组；方向光、点光、聚光、柔光；画布拖动及 12 组布光预设 |
| 人像预设 | 通用、长者、成人、少年各 8 项，共 32 项；搜索、强度调整、单张预览与批量套用 |
| 画布对照 | 单框／双框、滚轮与滑块缩放、平移、原图／滑动对比／处理结果；悬停某框按 V 仅轮换该框 |

年龄分类由用户选择，不自动推断年龄。去痘预设提供候选，仍需人工决定每一处是否修补。痣、雀斑、妆容和皱纹应由使用者检查保留。

## 模型与设备

| 文件 | 用途 | 权重许可 |
|---|---|---|
| `face_landmarker.task` | 五官定位与保护区域 | Apache-2.0 |
| `selfie_multiclass_256x256.tflite` | 人物、皮肤、头发与背景分区 | Apache-2.0 |
| `depth_anything_v2_vits.pth` | 光影所用的近似深度 | Apache-2.0 |
| `joint_20210926.pth` | ModelScope 局部瑕疵检测与修补 | Apache-2.0 |
| `pytorch_model.pt` | ModelScope 神经均肤 | Apache-2.0 |

模型和来源代码记录了下载地址与校验值，见[模型许可说明](licenses/V2_MODELS_NOTICE.txt)。权重随 Release 分享包分发，未提交进 Git 源码。旧 IC-Light、扩散基座等未使用模型不随本版打包。

CPU 可执行处理；兼容 CUDA 的 NVIDIA GPU 用于神经修补、均肤及深度推理。像素合成、几何采样与文件编码当前仍在 CPU。AMD／Intel 可选择 CPU，尚未提供对应专用推理后端。建议 32 GB 内存，为解压、照片与缓存预留空间；高像素照片和 CPU 模型推理需要等待。

实测环境为 RTX 5060 Ti 16 GB；CPU 均肤也通过验证。4070 Ti 12 GB 属于预期可用的 CUDA 硬件，但未在该型号实测。不根据单机结果承诺所有显卡的速度或统一最低显存。

## 格式与验证边界

导入单帧 JPEG、PNG、TIFF、WebP，单张最多 8000 万像素；按 EXIF 方向和 ICC 转为 8-bit sRGB。内部处理采用 float32 线性 RGB，最终导出原尺寸 **8-bit sRGB PNG**。当前不支持 RAW 或 16-bit 交付。

画布以 512 像素原尺寸图块读取。拖动期间的交互代理最长边为 1280，停手后的细化和导出使用同一原尺寸处理函数。处理顺序为原图与修补 → 修片 → 局部 → 光影 → 保护 → 单次逆向塑形 → 编码。

近似深度布光修改原片像素、保持环境与构图；不能消除原有投影、重建过曝细节或产生准确的遮挡阴影。二维塑形可能牵动附近发丝及背景。人像识别与皮肤分区可能误检，皮肤专项目前一次选择一个修片人物。

开发阶段通过 175 项后端回归，并用一张独立授权原片测试全部 32 项预设、真实模型推理、局部修补和逐像素导出一致性。分享包另做依赖、换目录启动和处理检查。尚未在全新 Windows 虚拟机或大量不同人物照片上完成系统性验证；没有同原片的质镜成片，不能宣称达到或超过质镜。

## 源码与构建

新编辑器位于 `experiments/portraitlab_v2/`（保留研发目录名）；桌面入口为 `packaging/V2Launcher.cs`。顶层 `portraitlab/` 与 `web/` 保留旧实现及共用模块，不应把旧界面当作 0.7.0 的入口。

开发入口（参数放在同一命令行）：

```text
python -B -m experiments.portraitlab_v2.server --data YOUR_DATA_DIR --port 18891
  --analysis-models ANALYSIS_MODELS --ai-python AI_PYTHON
  --neural-models NEURAL_MODELS --vendor VENDOR_DIR
```

核心环境使用 FastAPI、uvicorn、python-multipart、Pillow、OpenCV、NumPy、MediaPipe；模型环境使用 PyTorch 和固定网络代码。版本与结构见模型目录及发行文件清单。服务只监听 `127.0.0.1`，不得当作公网服务部署。

`packaging/v2_build_launcher.py` 构建桌面启动器；`packaging/build_v2_share.py build` 用白名单收集已审查组件，`verify` 校验分享目录，`archive` 生成完整 ZIP 或 GitHub 普通 ZIP 分包。使用 `--help` 查看必要的组件路径。构建器拒绝覆盖现有目标，不复制用户照片、记录、本机配置与缓存。
