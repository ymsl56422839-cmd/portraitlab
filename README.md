# 照影 · PortraitLab

本地人像处理的开源 Windows 软件：一键预设、批量修肤、矩形局部调整、保护笔刷、原尺寸导出，以及 **画布交互布光**。包含四类 52 个修片预设、独立去痘强度、10 个交互布光预设、自定义与收藏，以及 CPU／GPU 设备选择。

**0.4.1 是面向 0.4.0 完整包的小补丁：新增矩形局部调整、四类 52 个预设、独立去痘强度，增强模型入口，并支持鼠标悬停视窗时按 V 轮换显示。无需重新下载大运行时。** 0.4.0 已将“光影重塑”改为原片上的交互布光；0.3.0 及更早的软件包采用旧生成式主界面。详见 [0.4.1 补丁说明](docs/RELEASE_0.4.1.md)。

修肤使用 MediaPipe 定位／分割和 RapidRetouch 算法；交互布光使用 Depth Anything V2 Small 估计深度，再由确定性光照公式处理已有像素。首次分析完成后，在画布拖动光源即可预览。“保留调整”写入当前照片的独立灯光参数，不创建新照片。旧 IC-Light 后端与历史记录保留兼容，但不再作为主界面操作流程。

## 下载与启动

从 [Releases](https://github.com/ymsl56422839-cmd/portraitlab/releases) 下载 Windows 软件包。Core 包包含界面、经典修肤及其独立解释器；AI 运行组件包含 PyTorch、CUDA 库及推理依赖，也是经典 GPU 合成的运行环境。下载 Core 和全部 AI 分包，先解压 Core，再将所有 AI ZIP 解压到同一位置，合并同名 `PortraitLab-0.4.0-Windows` 文件夹。各分包都是普通 ZIP，无需拼接工具；缺少任何 AI 分包都可能导致布光分析不可用。

**已有 0.4.0 完整目录，只需下载 0.4.1 Upgrade 小补丁。新用户只需 0.4.0 完整包加 0.4.1 小补丁；本次不重新分发大运行时包。** 先在每个窗口保留或放弃草稿，**关闭所有照影窗口**，再把补丁 ZIP 全部内容解压到原软件目录，与 `PortraitLab.exe` 同级并覆盖程序文件。保留 `runtime`、`AI`、`Data` 和 `Cache`。不要只复制 EXE，也不要在原目录内再建一层软件目录。完整 0.2.0／0.3.0 的运行时同样列入升级包兼容基线；实际验收范围以补丁说明为准。重新开一个窗口不会自动替换仍在运行的旧后台。

双击 **PortraitLab.exe** 直接进入修图界面，无需另装 Python、Git 或运行终端命令。日志入口在设置中；关闭软件会停止该窗口启动的服务。存在运行任务时会先提醒。

系统要求 Windows 10／11 x64、[Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/) 和 [Microsoft Visual C++ 2015–2022 x64 Runtime](https://aka.ms/vs/17/release/vc_redist.x64.exe)。许多电脑已安装；缺少时软件提供微软官方安装入口。应用不捆绑完整浏览器。已验证中文目录迁移，尚未在全新 Windows 虚拟机验证全部系统前置条件。

软件可放在可写的任意盘符与中文目录。默认 Data 保存模型、原片副本、编辑记录与输出，Cache 保存运行缓存。可使用启动参数 --data、--cache 或环境变量配置位置。程序只监听 127.0.0.1，不作为公网服务部署。

公开软件包不包含模型权重。首次使用：

1. 点击照片库下方常驻的“模型下载与设备”。基础处理模型和布光分析模型各有状态与操作按钮；未下载时选择下载，已下载时选择校验，通过后显示已就绪。
2. 使用交互布光时，准备约 99 MB 的深度分析模型；分析依赖独立 AI 运行组件，也可从“光影重塑”中准备。无需下载旧 IC-Light 与扩散基座；新增去痘复用现有算法，不要求新模型。
3. 模型准备后导入照片。下载来自清单固定的上游地址，逐文件校验 SHA-256；中断后可重试。

模型下载需要联网，照片处理使用本机模型。推理不会为了补齐模型而自动联网。应用没有实现照片上传服务；第三方 SDK 的网络行为仍受其实现影响，验证边界见文档。

## 硬件与通用性

| 使用方式 | 建议 |
|---|---|
| 经典修肤 | Windows x64、CPU；无需 NVIDIA 显卡。安装 AI 组件后可选 NVIDIA GPU 合成加速 |
| 布光分析 | CPU 可用；兼容 CUDA 的 NVIDIA GPU 可选，首次初始化不一定比 CPU 快 |
| 实时灯光预览 | 优先 WebGL2 图形加速；不可用时自动使用长边最多 384 像素的 CPU 预览 |
| 原尺寸布光导出 | CPU 分块计算；使用保存的参数和估计几何，无需再次运行扩散模型 |
| 内存与磁盘 | 建议 32 GB 内存；完整运行时和模型约 11 GB，另为解压、原片和输出预留空间 |

当前实测硬件是 RTX 5060 Ti 16 GB、Intel Core i7-11700。交互布光已验证 CPU 和 CUDA 分析；无需把旧扩散生成的 8 GB 显存目标套用于此流程。4070 Ti 12 GB 具备目标能力，但该具体型号未实测；不据单机测试承诺统一最低显卡型号。

深度分析尚未接入 AMD／Intel 专用推理后端，仍可使用 CPU。画布 WebGL2 预览可使用浏览器支持的图形设备，是否硬件加速取决于驱动与浏览器。首批发行与验证面向 Windows x64；其他平台尚未完成同等打包验证。驱动需要支持随 AI 组件提供的 CUDA 12.8 运行时，无需单独安装 CUDA Toolkit。

## 使用流程

- **修肤：**导入照片，选择预设并检查自动选区。保护笔刷排除经典修肤与面部局部提亮，不能阻止全局曝光／色彩调整。
- **导入：**顶部和空白画布均可导入；文件或文件夹可以拖入。打开布光模块时，导入后选择新照片并准备分析。
- **预设：**“通用、长者人像、成人人像、少年人像”四类常驻，共 52 个方案；原 22 个预设的 ID 和数值参数保留。可按用途筛选、搜索、收藏或保存自定义参数。类别由用户选择，不自动识别年龄；长者方案默认关闭磨皮、纹理柔化和去痘。手动修改后显示已微调。
- **矩形局部调整：**选择“矩形选区”后在任一视窗拖出区域，可移动、缩放或重画。此时预设、手动参数与效果强度只追加作用于该矩形，边缘向内羽化；修肤仍受自动皮肤选区和保护笔刷限制。“完成选区”保留效果，删除选区移除局部调整。每张照片目前保留一处矩形，与全局参数分开保存。
- **去痘：**独立“去痘强度”修复识别到的面部痘点，不依赖增加磨皮。可先框选再使用；强度调节修复量，不扩大检测范围。连片痘痕可能漏检，雀斑可能误判，不能保证所有痘点准确识别；可用保护笔刷保留痣、雀斑与妆面。
- **批量：**明确选择目标照片后只同步全局数值参数，支持撤销上次批量操作。每张图保留自己的矩形局部调整与保护笔刷；局部编辑时禁用批量。自定义预设保存当前编辑范围的参数，不保存矩形位置或笔刷。
- **交互布光：**选择照片进入“光影重塑”，首次分析完成后选择预设或添加光源。在画布拖动光源和聚光目标，或调节色温、强度、方向、柔度。最多同时启用 4 盏灯；作用范围可选“仅主体 · 保留背景”“仅背景 · 保留主体”或“整张照片”，默认仅主体。打开“显示作用选区”可检查当前范围与发丝边缘，高亮不会写入照片；开始调灯时自动关闭高亮，显示实际效果。
- **保留与撤销：**点击“保留调整”保存到当前照片。离开未保留的布光时提供保留、放弃、继续编辑。修片与布光参数独立，“重置修片”保留布光。照片库支持单张／多张移除和撤销，外部原文件不删除。
- **大图对照：**单视图、双视图均支持原图、滑动对比、处理结果；滚轮或滑块缩放，两窗同步平移。鼠标停在图像区域时，按 **V** 依次轮换该视窗的原图 → 滑动对比 → 处理结果；输入文字、弹窗及拖动期间不触发。

交互布光保留原片构图，预览长边最多 1024 像素，导出按原尺寸重算。仅主体时保留背景，切到仅背景时保留主体；完全未选中的像素保留修片底图数值，羽化边缘按选区权重过渡。整张照片模式同时影响人物与背景。不代表消除原有阴影、恢复过曝或完成准确三维重建。边缘取决于分割精度，JPEG 压缩也可能改变导出像素。详见 [交互布光方法与来源](docs/INTERACTIVE_LIGHTING.md)。

中央状态区区分正在预览、尚未保留和已保留；实际绘制完成后才提示更新。修片预览、保存与导出共用原尺寸全局及局部修片底图，保存预览采用无损 PNG。旧缓存会按新版处理签名重算；旧版直接缩图修片与新版原尺寸处理后缩图可能存在细节差异，保留旧参数不等于旧预览逐像素相同。原尺寸导出与缩小预览仍有重采样差异。界面与后台版本不匹配时会明确提示关闭全部窗口重启。

设置中的经典处理设备支持自动、CPU 和 NVIDIA GPU。GPU 执行曝光、面部局部曝光合成、冷暖、饱和度、整体混合及 sRGB 编码；人脸识别、分割、修肤和文件压缩仍在 CPU。自动模式可回退并显示原因，明确选择 GPU 时不可用会报错。布光分析单独选择 CPU、自动或 NVIDIA GPU，实时预览设备与分析设备分别显示。

## 格式与数据

导入支持单帧 JPEG、PNG、TIFF、WebP；不支持 RAW、动画和多页图像。每批导入最多 50 张，单文件最多 100 MiB，单图最多 80 MP。程序保留原始文件副本，工作图按 EXIF 转正并转换到 8-bit sRGB。

JPEG、PNG、TIFF 导出均为 **8-bit sRGB**，嵌入 ICC；不复制原图 EXIF。经典修肤与交互布光可按原尺寸重算，历史生成图按其实际尺寸导出。输出不覆盖原片，附带参数与来源 JSON。

便携默认数据位于软件目录，也可通过 PORTRAITLAB_DATA、PORTRAITLAB_CACHE 配置。PORTRAITLAB_AI_PYTHON 指向独立 AI 解释器，PORTRAITLAB_RELIGHT_MODELS 指向 AI 模型目录。PORTRAITLAB_STORAGE_ROOT 是可选的写入根限制；默认不绑定固定盘符。源码检出的布局详见复现文档。

## 从源码运行和构建

准备 64 位 Python 3.12，在源码目录执行：

    .\setup.ps1 -PythonPath <python.exe路径> -DownloadModels
    .\Launch.cmd

经典环境使用 requirements.lock.txt。AI 使用独立环境，CUDA Torch 固定为 2.7.1+cu128，其余依赖及模型清单随源码提供。安装 AI 的具体命令和便携构建步骤见 [构建说明](docs/BUILDING.md)，实验记录方式见 [复现说明](docs/REPRODUCING.md)；直接下载便携包不需要执行这些命令。
