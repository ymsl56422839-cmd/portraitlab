# PortraitLab

PortraitLab 是用于本机人像处理的中文研究工具：批量导入与导出、同步参数、逐张调整、保护笔刷和前后对比，共用同一套处理引擎。

第一版采用 **MediaPipe 定位与分割 + RapidRetouch 的非生成式图像处理**。修肤包含分频去瑕疵、平滑、匀肤与纹理柔化；局部修光是随人脸定位的径向曝光调整。它没有集成 IC-Light、LBM 或 ModelScope 神经修肤，也不声称复现质镜的光场生成器。

## 在 Windows 上启动

将整个源码目录保存在 `F:\codex` 内，准备 64 位 Python 3.12（本版在 3.12.14 验证）。首次在该目录打开 PowerShell：

```powershell
.\setup.ps1 -DownloadModels
.\Launch.cmd
```

安装脚本在 F 盘创建 Python 环境并安装依赖；`-DownloadModels` 从 Google 官方地址获取两份 MediaPipe 模型，并校验清单里的 SHA-256。权重不随源码包分发。若需指定已有 Python，可使用 `setup.ps1 -PythonPath <python.exe 的绝对路径> -DownloadModels`。

`Launch.cmd` 默认用已安装的 Edge 或 Chrome 打开 `http://127.0.0.1:18765`，并为本程序指定 F 盘独立浏览器配置、磁盘缓存和崩溃记录目录。未找到支持的浏览器时会打印本机地址，供手动打开；也可运行 `Launch.ps1 -NoBrowser`，或通过 `-Port` 指定本地端口。停止运行时关闭启动的服务进程；页面关闭不等于服务停止。

## 使用流程

1. 导入照片，选择当前照片；先检查人脸与皮肤区域是否识别正确。
2. 从低强度开始调整修肤、色彩与局部曝光，使用前后对比观察纹理、五官、妆容及皮肤边缘。
3. 用保护笔刷排除痣、胡须、特殊妆容或误判区域；恢复笔刷只恢复自动皮肤区域。保护笔刷同时排除该处的局部曝光，但不阻止全局曝光与色彩调整。
4. 将确认好的数值参数同步到选中的照片，再逐张检查；同步不复制笔刷位置，不同拍摄条件通常需要分别调整。
5. 导出新文件并检查导出结果。原始照片、参数、预览和导出文件应分别保留。

未检出人脸时，程序跳过依赖人脸的修肤与局部修光，并提示原因；全局色彩调整仍可使用。模型缺失或校验失败会报错，不会用普通滤镜冒充模型推理。

## 格式与导出

导入支持单帧 PNG、JPEG、TIFF 和 WebP；不支持 RAW、动画和多页图像。每批最多 50 张、单文件最多 100 MiB、总计最多 512 MiB，单图最多 80 MP。导入保留原始文件副本，另生成按 EXIF 转正、ICC 转换到 sRGB 的 8-bit RGB 工作图。

导出 PNG、JPEG 或 TIFF 均为 **8-bit sRGB**，嵌入 sRGB ICC，不复制原图 EXIF；相机信息保留在原始副本中。导出使用全分辨率工作图，不把预览放大充当成片。文件名包含照片和任务标识，遇到同名文件增加序号；同时保存该次参数与笔刷快照的 JSON 旁车文件。

## 数据位置

本次发行的运行根目录默认是本任务的 `work\portraitlab`。源码移到普通检出目录后，运行根目录默认改为源码下的 `.local`；`PORTRAITLAB_WORK` 可覆盖这个根目录。

- `runtime`：模型、导入副本、工作图、分析缓存、预览、参数、导出和服务日志。
- `venv`：独立 Python 环境。
- `temp`：安装与启动进程的临时目录。
- `cache`：依赖缓存及本程序启动的独立浏览器配置、缓存和崩溃记录。

`PORTRAITLAB_DATA` 只覆盖运行数据目录，默认是上述根目录下的 `runtime`。所有可配置写入路径仍须在 `F:\codex` 内；这是本发行配置的约束，不是算法本身的限制。已有操作系统或浏览器数据不会因此迁移；手动用其他浏览器打开页面时，其自身存储遵循该浏览器设置。

图像处理在本机服务中完成，应用层没有实现照片上传服务。首次安装依赖和下载模型需要联网。2026-11-13 验证后依赖锁定为 MediaPipe 0.10.21：两张本地样片完成分析、渲染与关闭，未观察到 Clearcut 日志。先前试用 0.10.35 时曾出现 Clearcut 发送失败日志；未确认其请求目标或内容。当前检查未做网络抓包，不能证明 SDK 完全不出网，也不能据初次失败日志断言照片已上传。服务仅用于本机，不应改为公开监听地址。
