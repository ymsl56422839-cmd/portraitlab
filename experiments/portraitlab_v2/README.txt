照影 V2 · 0.7.0 完整编辑器（源码目录沿用 V2）

独立发行入口；0.7.0 分享包包含本模块、运行环境及五项模型。旧版不自动迁移编辑记录。

已接通的编辑流程
  修片：神经均肤、质感柔肤、肤色与泛红、已确认范围的痘印色泽、眼周、
        反光、细纹、面部曝光，以及全图曝光/冷暖/色调/对比/饱和/阴影/高光。
  局部：矩形范围的独立修片参数、内侧羽化、保护笔刷与擦除保护。
  瑕疵：自动候选逐点确认、手动涂抹修补、整次修补组开关与撤销。
  塑形：脸宽、面颊、下颌、下巴、额头，左右侧分别调整；推拉、局部恢复、
        固定范围和画面边缘保护。多个已识别人物可分别配置塑形参数。
  光影：主体/背景独立灯组；方向光、点光、聚光、柔光；画布拖动光源，
        调整方向、强度、色温、光束、范围等；12组光影预设。
  预设：通用/长者/成人/少年各8项，共32项；搜索、强度、单张草稿和批量套用。
        年龄分类由使用者选择。去痘类只提供候选，须人工决定每一处是否修补。
  照片库：文件导入、文件拖入、多选、单张/批量移除；源文件保持不变。
  模型：显式校验、点击下载、权重与代码/运行组件分开显示、自动/CPU/NVIDIA GPU。

如何操作
  1. 导入照片，或直接把照片文件拖进画布。
  2. 顶部“模型与计算设备”查看依赖，首次使用点击检查。
  3. 右侧选择修片/塑形/光影/预设。人像专项先点击该模块的准备按钮。
     基础曝光与色彩不需要模型准备。
  4. 调整后画布显示草稿。拖动期间使用有标识的交互预览，停手后细化。
     当前可见原尺寸图块全部载入并无错误后，才允许“保留调整”。
     “取消草稿”恢复已保留画面；保留后可继续编辑或导出。
  5. “全部恢复原图”常驻画布顶部，关闭修补、修片、塑形和光影，
     已保留内容可用一次撤销找回。普通撤销/重做保留跨模块编辑记录。
  6. 框选后切“框选区域”调整，全图参数仍保留。保护范围保留原片像素。
     塑形后，修补/框选/保护在原图视窗标记，范围随后随塑形显示；
     塑形推拉和恢复则在处理结果视窗操作。
  7. 单/双视图均可独立选择原图、滑动对比、处理结果。
     鼠标所在视窗按 V 轮换；滚轮/滑块缩放，空格拖动平移。
  8. 导出 PNG 不覆盖原片，输出与参数记录写入独立 data/exports。

图像与响应
  100%为原图一像素对应一CSS像素，始终读取原尺寸图块，高DPI屏幕由浏览器映射。
  交互代理只用于拖动过程，最长边不超过1280；最终细化与导出使用同一原尺寸函数。
  顺序：原图+修补→修片→局部→光影→保护→单次逆向塑形→编码。
  导入为8-bit sRGB，内部float32线性RGB，最后输出8-bit sRGB PNG。
  当前不是RAW或16位交付。GPU选项作用于神经修补/均肤/深度推理，
  确定性合成与几何采样目前使用CPU。

验证范围与实际边界
  后端175项自动化回归通过，包含像素范围、线性/分块一致性、草稿版本、历史、
  模型下载事务、便携模型目录及代理采样。浏览器与真实模型记录在独立验收目录。
  一张7643×5098授权原片已运行全部32项预设、真实均肤/深度准备和组合导出。
  本机组合测试：交互首帧约0.69秒、移动光源后约0.41秒；512原尺寸图块约0.47秒；
  一个覆盖约1700万像素的缩放视图细化约10.93秒；全尺寸导出约26.85秒。
  这是本机单图测量，不是不同电脑的性能保证，首次模型加载需要等待。
  分析模型仍可能误判或漏掉人物。皮肤专项目前一次选择一个修片人物；
  更换人物前需恢复当前修片，避免已有参数被套给另一人。
  近似深度布光修改现有像素、保留环境；不能消除原有投影、重建过曝细节
  或生成真实遮挡阴影。塑形为局部二维形变，强调整可能牵动附近头发/背景。
  痣与雀斑不会因预设被自动删除，但可能进入候选；人工勾选的候选会被修补。
  只有一张独立授权原片，没有同原片的质镜成片，不能据此宣称达到或超过质镜。

开发启动
  python -B server.py --data ABSOLUTE_DATA_DIR --port 18891
    --analysis-models MEDIAPIPE_MODEL_DIR --ai-python AI_PYTHON
    --neural-models VERIFIED_MODELSCOPE_WEIGHTS_DIR --vendor VERIFIED_VENDOR_DIR
  主进程TEMP/TMP与工具缓存要显式配置。模型进程使用data/cache/worker短目录，
  不将缓存放在层层嵌套的任务输出下；Windows根缓存超过200字符时明确报错。
  下载只在点击后发生，只写独立data/models；配置保存相对覆盖目录，重启可读取。
  核心环境：FastAPI、uvicorn、python-multipart、Pillow、OpenCV、NumPy、MediaPipe。
  AI环境：兼容PyTorch及固定版本网络代码。发行构建与迁移验证见 docs/PORTABLE_0.7.0.md。
  直接运行 server.py 时需自行停止服务；0.7.0 桌面启动器关闭窗口会停止所属服务。
